# hello

## 蘑菇训练场

按 [PLAN.md](./PLAN.md) 逐项实现的单关横版动作网页小游戏。

当前进度：T3 完整关卡地形、背景与相机（2560 宽横向卷轴、5 个平台、视差背景）。

### 操作

| 按键 | 动作 |
| --- | --- |
| `←` / `→` 或 `A` / `D` | 左右移动 |
| `Space` | 跳跃（仅地面，不能空中连跳） |

### 运行

页面使用 ES Modules，需要通过静态服务器打开（不能直接双击 `index.html`）：

```bash
python3 -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000>。
