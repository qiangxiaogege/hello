# hello

## 蘑菇训练场

一个零依赖、零构建的单关横版动作网页小游戏，按 [PLAN.md](./PLAN.md) 实现。

### 运行

页面使用 ES Modules，需要通过静态服务器打开（不能直接双击 `index.html`）：

```bash
python3 -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000>。

### 操作

| 按键 | 动作 |
| --- | --- |
| `←` / `→` 或 `A` / `D` | 左右移动 |
| `Space` | 跳跃（仅地面，不能空中连跳） |
| `J` | 近战攻击（有前摇、命中帧与冷却） |
| `Enter` 或点击画面 | 开始游戏；胜利/失败后重开 |
| `R` | 胜利/失败后重开 |

### 目标

关卡里共有 8 只蘑菇怪。用 `J` 击败全部蘑菇怪后，关卡尽头的传送门会亮起；走进传送门即可通关。

玩家有 3 颗心，碰到敌人扣 1 颗心并获得约 1.2 秒无敌时间；心数归零则失败。失败或通关后可按 `R` / `Enter`（或点击画面）直接重开，不需要刷新页面。

### 当前进度

T1–T7 已完成：

- 1280×720 逻辑分辨率，等比缩放并居中；固定步长主循环，切换标签页不会追帧。
- 2560×720 横向卷轴关卡、P1–P5 平台、视差山与云、相机跟随与边界钳制。
- 玩家移动、跳跃、平台碰撞、攻击、受击无敌与 3 颗心生命值。
- 8 只蘑菇怪的巡逻、平台边缘掉头与 340px 内追击。
- 剩余蘑菇计数、传送门、开始/胜利/失败界面、计时与不刷新页面重开。
- 受击闪白、屏幕震动、击杀粒子、敌人死亡淡出、挥砍轨迹等视觉反馈。

### 文件结构

| 文件 | 职责 |
| --- | --- |
| `index.html` / `styles.css` | 页面骨架与 Canvas 布局 |
| `src/main.js` | 启动与固定步长主循环 |
| `src/config.js` | 分辨率、物理、战斗、关卡与颜色常量 |
| `src/input.js` | 键盘状态与按键边沿检测 |
| `src/player.js` | 玩家移动、跳跃、攻击与受击 |
| `src/enemy.js` | 蘑菇怪巡逻、追击、受击与死亡 |
| `src/level.js` | 关卡数据、出生点、传送门与相机 |
| `src/game.js` | 世界状态、碰撞、战斗、胜负与重置 |
| `src/render.js` | 背景、地形、角色、敌人、HUD 与特效绘制 |
